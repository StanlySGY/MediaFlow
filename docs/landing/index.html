MediaFlow

长音频切分 · OpenAI 兼容 ASR 流式转写 · 无损音视频合并。FastAPI / asyncio / FFmpeg + React 控制台。

截图中的 ASR 地址已改写为 asr.internal，不含真实内网 IP。

本项目不含任何 ASR 模型。MediaFlow 只发 HTTP 请求，识别质量等于你的上游模型质量；diarization 同样由上游负责。

30 秒接起来

cp .env.example .env            # 填 ASR_API_KEY
pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8080

能力

  • 多格式输入（mp3/wav/m4a/flac/aac/ogg/pcm/mp4/mov/mkv），FFmpeg 归一化为 16k mono pcm_s16le
  • 三种切分策略：fixed / silence / overlap
  • 分片并发调用 ASR（信号量限流）+ 指数退避重试 + 失败分片隔离
  • SSE 推送每个分片结果，多订阅 + 历史回放，刷新页面不丢消息
  • 时间轴感知拼接；无 word 时间戳时回落最长公共子串去重
  • SRT / VTT 字幕导出，前端双击校对后可导出精修字幕
  • 实时 pipeline：realtime_mock / realtime_http / realtime_ws / realtime_offline
  • 无损合并：POST /media/concat，concat demuxer + -c copy，不转码
  • 可选 Bearer Token 鉴权；SSE 用短期 HttpOnly cookie
  • 单 worker 运行：任务状态 / SSE 订阅 / 实时会话都在进程内存
