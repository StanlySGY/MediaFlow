# 改进范围

基于可信内网、单用户、单机、长期运行定位，修复审查中影响日常可用性和交付质量的问题。

## 必须处理

- 文件任务清空时请求后端取消，避免页面状态与后台任务脱节。
- 实时录音异常/组件卸载时释放已创建的服务端 session。
- 将实时容量检查和注册放入同一临界区，避免快速重复创建超过上限。
- 为实时 offline provider 增加会话累计音频字节数/时长上限。
- 防止 `.env` 被 Git 跟踪，并保留 `.env.example`。
- 修复前端 lint 和 Ruff 静态检查问题，补齐 CI 门禁。
- 在 UI 明确显示 realtime mock 为演示模式；去除生产页面对 Google Fonts 的强依赖。

## 约束

- 不引入 Redis、数据库、多租户权限或公网级 SSRF 防护；这些属于未来扩大部署面的前置项。
- 保留用户已有工作区改动，不修改 `handoff.md`、`.v2c/`、`.zcode/` 和根目录 `node_modules/`。
- 优先补回归测试，再修改实现；变更保持在与上述问题直接相关的文件。
